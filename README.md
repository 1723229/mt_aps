## 功能特性

- ✅ **多阶段调度**: 5个阶段渐进式优化
  - Phase 1: 班组班次规划 (BC-11)
  - Phase 2: 独占产品优先 (BC-06保证)
  - Phase 3: 优先级产品调度
  - Phase 4: 剩余产品调度 (BC-07保证)
  - Phase 5: 换产优化 (BC-09保护)

- ✅ **区域约束**: 支持4种区域特殊规则
  - A类: 老包装区间 (固定搭配 + 1空闲)
  - B类: 新包装A区 (灵活分配 + 最多1空闲)
  - C类: 新包装B区 (严格绑定 + 双班)
  - D类: 新包装CD区 (2双+2单配置)

- ✅ **换产优化**: 自动计算换产损耗，优化产能利用
- ✅ **优先级管理**: 支持产品优先级和时间约束
- ✅ **产能优化**: 实际产能利用率达到97.28%

## 算法说明

### 多阶段贪心调度器 (优化版)

#### Phase 1: 班组班次规划
- 周内固定班次 (BC-11)
- 跨周切换班次
- 建立 `crew_shift_map`

#### Phase 2: 独占产品优先调度 ⭐ **优化**
- **移至Phase 2 (原Phase 3)**
- 识别仅在单条产线生产的产品
- 按剩余量排序（大产品优先）
- **确保独占产品获得优先容量** (BC-06保证)

#### Phase 3: 优先级产品调度
- 处理 `product_priority` 约束
- 在指定日期范围内调度指定吨数
- 吨瓶转换: `瓶数 = 吨数 × 500 × 2124 ÷ spec`

#### Phase 4: 剩余产品调度 ⭐ **优化**
- **Step 1**: 确保所有未调度产品至少获得一个班次 (BC-07)
- **Step 2**: 继续完成部分调度产品
- 按优先级和剩余量贪心分配

#### Phase 5: 换产优化 ⭐ **优化**
- 计算换产损耗（10%）
- 优先相同酒质换产
- **BC-09保护**: 检查不违反产品连续性

### 关键优化点

1. **独占产品优先** (Phase顺序调整)
   - 问题: 独占产品容量被挤压
   - 解决: 移至Phase 2，确保优先容量

2. **100%产品覆盖** (Phase 4增强)
   - 问题: 部分产品未调度
   - 解决: 显式确保所有产品至少调度一次

3. **连续性保护** (Phase 5增强)
   - 问题: 换产破坏产品连续性
   - 解决: 换产前检查不违反BC-09
